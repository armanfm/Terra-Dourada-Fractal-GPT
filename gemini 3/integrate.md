The application first runs a local Rust recall engine that searches a user-provided `mind.bin` and returns a “sovereign recall” fragment. When recall is found, the server builds a prompt that explicitly includes the recall output and asks Gemini 3 to produce a clear, direct answer based on that content (hybrid deterministic mode). When recall is not found, the system can fall back to Gemini 3 to produce a normal response (generative mode).

Gemini 3 is used through the `generateContent` endpoint with a configurable `generationConfig` (temperature and max output tokens) to control style and verbosity. The integration is essential because it transforms raw recall fragments into a readable, coherent answer without changing the underlying facts, since the ranking and selection of memory remain local and deterministic. The app also implements timeouts and retry logic around Gemini calls to keep the demo stable under transient errors, and reports token usage when available.
